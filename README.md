# AI Lead Qualification Telegram Bot

A no-code AI automation project built with Make.com, OpenAI, and Telegram to capture, qualify, and organize incoming leads.

## What the workflow does

- Receives incoming messages from Telegram
- Handles both button-based and free-text conversations
- Collects lead information step by step
- Uses AI to understand user messages and questions
- Qualifies leads based on collected information
- Routes users through different conversation paths
- Stores structured lead data
- Supports manager handoff after qualification
- Sends notifications when a lead is ready for human follow-up

## Tools Used

- Make.com
- OpenAI
- Telegram Bot API
- Webhooks
- Google Sheets
- Routing, filters, and conditional logic

## Workflow Structure

Telegram Bot → Make.com → Routing & Filters → OpenAI → Lead Qualification → Data Collection → Manager Handoff

## Project Goal

The goal of this project was to automate the first stage of customer communication so a business can respond to leads faster, collect useful information automatically, and send qualified prospects to a manager.

## Key Features

- Conversational lead qualification
- Free-text AI responses
- City and service selection
- Date collection and validation logic
- Structured lead information
- Automated routing
- Human handoff
- Manager notifications

## Security

API keys, bot tokens, webhook secrets, and private credentials are not included in this public repository.
